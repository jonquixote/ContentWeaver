# Phase 1: Auth & Security — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every auth/security hole. Real JWT auth enforced on all routes, argon2 password hashing, owner-scoping (fix IDOR), CORS lockdown, secure `me` endpoint. Remove hardcoded user IDs.

**Architecture:** Backend-only. JWT bearer auth middleware via `@auth_required` decorator applied per-route (routes were previously decorated with `@jwt_required` but auth was mocked). Add `current_user` injection. Replace Werkzeug `generate_password_hash`/`check_password_hash` with Argon2 (phc format). Scope all queries by `current_user.id`. Frontend gets real session (no changes needed except removing mock fallbacks).

**Tech Stack:** PyJWT (already pinned 2.10.1), argon2-cffi (new dep), python-dotenv.

## Global Constraints

- Backwards-compatible: existing users must still log in (Werkzeug-hash check falls back before re-hashing to argon2 on next login)
- Tokens: HS256, expiry 24h, `user_id` + `username` claims
- All `/api/*` routes except `/auth/register`, `/auth/login`, `/health` require `@auth_required`
- CORS `origins` = `http://localhost:5173` (Vite default) — never `*`
- Never return the password hash in any response
- Frontend `AuthContext` must keep working unchanged — `me` response shape preserved

### Task 2: Argon2 password hashing with Werkzeug fallback

**Files:**
- Modify: `money_weaver_backend/src/models/user.py`

**Interfaces:**
- Consumes: User model
- Produces: `hash_password`, `verify_password` using argon2 with phc format detection fallback

- [ ] **Step 1: Replace hash methods**

In `User` model, replace `generate_password_hash`/`check_password_hash` calls:

```python
from argon2 import PasswordHasher
from argon2.exceptions import VerifyMismatchError, VerificationError, InvalidHashError

_ph = PasswordHasher()

def hash_password(self, password):
    self.password_hash = _ph.hash(password)

def verify_password(self, password):
    try:
        return _ph.verify(self.password_hash, password)
    except VerifyMismatchError:
        return False
    except (InvalidHashError, VerificationError, AttributeError):
        return self._legacy_verify(password)

def _legacy_verify(self, password):
    if not self.password_hash:
        return False
    ok = werkzeug.security.check_password_hash(self.password_hash, password)
    if ok and not self.password_hash.startswith('$argon2'):
        self.password_hash = _ph.hash(password)  # upgrade on next login
        return True
    return ok
```

Note: `self.password_hash = _ph.hash(password)` — need `db.session` commit where `verify_password` is called (in auth route), OR flag `self.needs_hash_upgrade`. Simplest: in the auth login route after successful verify, if hash was upgraded, commit. Store a module-level set of pending-upgrade users, or just commit unconditionally in login route (cheap).

- [ ] **Step 2: Fix register route to use new hasher**

In `src/routes/auth.py` register, replace `user.set_password(password)` with `user.hash_password(password)`.

### Task 3: Real auth middleware + enforce on all routes

**Files:**
- Create: `money_weaver_backend/src/auth.py` (decorator)
- Modify: `src/routes/user.py`, `src/routes/project.py`, `src/routes/task.py`, `src/routes/api_keys.py`, `src/routes/video_generation.py`, `src/routes/voice_cloning.py`, `src/routes/auth.py` (`me`, `logout`)

**Interfaces:**
- Produces: `@auth_required` decorator; every protected route validates JWT and sets `g.current_user`

- [ ] **Step 1: Create decorator `src/auth.py`**

```python
import os
from functools import wraps
from flask import request, jsonify, g
import jwt

def auth_required(f):
    @wraps(f)
    def wrapper(*args, **kwargs):
        auth = request.headers.get('Authorization', '')
        if not auth.startswith('Bearer '):
            return jsonify({'error': 'Missing or invalid token'}), 401
        token = auth[7:]
        try:
            payload = jwt.decode(token, os.environ.get('SECRET_KEY', ''), algorithms=['HS256'])
        except jwt.ExpiredSignatureError:
            return jsonify({'error': 'Token expired'}), 401
        except jwt.InvalidTokenError:
            return jsonify({'error': 'Invalid token'}), 401
        g.current_user = {'id': payload['user_id'], 'username': payload['username']}
        return f(*args, **kwargs)
    return wrapper
```

- [ ] **Step 2: Apply decorator to all routes**

Decorate every route in `user.py`, `project.py`, `task.py`, `api_keys.py`, `video_generation.py`, `voice_cloning.py`, and `auth.py` `me`/`logout` with `@auth_required`. Leave `register`, `login`, `/health` public.

Route functions currently receiving `user_id` as path arg (e.g. `/api/users/<int:user_id>`) → change to use `g.current_user['id']` and drop the path param OR keep path but 403 if `user_id != g.current_user['id']`.

@app.route('/api/auth/logout', methods=['POST'])

def logout():
    token = request.headers.get('Authorization')[7:]
    payload = jwt.decode(token, os.environ.get('SECRET_KEY', ''), algorithms=['HS256'])
