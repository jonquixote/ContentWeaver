# Music Library

Drop royalty-free / CC0 tracks here from [Pixabay Audio](https://pixabay.com/music/) or [FreePD](https://freepd.com/) — audio files stay uncommitted (see `.gitignore`), only this README and `manifest.yaml` ship with the repo. List each track in `manifest.yaml` as `- file: <name>.mp3` with a `mood:` key matching the `music:` field of a niche profile (aliases handled in `src/services/video/music_service.py`).
